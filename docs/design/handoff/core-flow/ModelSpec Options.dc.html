Canvas first vs table first

Both share one spec bar (task box, chips, add condition), one funnel, one shortlist and one “why” panel. Only the hero changes. The connective tissue: every chip, canvas handle and table row edits the same spec, and the selected model is the same across all views. Each frame is live; pick a template or press Find models.

1aCanvas first (your instinct)

Trade-off canvas is the hero with the shortlist beside it; the table sits below as the deep dive. Best for builders deciding on two real axes.

1bTable first (challenger)

Sortable decision table is the hero with inline reasons per excluded model; the canvas becomes a smaller lens on the right. Best for platform engineers, analysts and reviewers.
