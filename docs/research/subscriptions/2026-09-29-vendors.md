# Subscription-only vendors: research round 1 (MODEL-205)

Read on 2026-09-29. The records are in `offerings/subscriptions/cursor.yaml`,
`github-copilot.yaml` and `perplexity.yaml`, and `scripts/model_205_collect.py`
writes them.

MODEL-201 (#363) found these plans but could not record them:
`registry/providers.yaml` kept app-only platforms out. They are now listed
under `subscription_vendors`. A vendor sells plans and nothing else, so it
never appears as a pay-per-use route (see `docs/decision-contract.md`,
"Subscription-only vendors").

added once its page names models, or once a harness for its tools is

## Cursor

Sources: https://cursor.com/docs/models-and-pricing
(`model-205-cursor-models-and-pricing`) and https://cursor.com/pricing
(`model-205-cursor-pricing`). Both were read over plain HTTP. The pricing page
shows only Pro and Teams Standard without JavaScript; the docs table has every
plan.

- Prices: "Pro | $20/mo", "Pro Plus | $60/mo", "Ultra | $200/mo". For Teams:
  "Standard ($40/user/mo) and Premium ($120/user/mo), where Premium adds 5x the
  Standard limits on Agent."
- Coverage, Pro to Ultra: "Pro, Pro Plus, and Ultra include two usage pools".
  The first is "Cursor Models: Significantly more included usage for Grok 4.7,
  Grok 4.6, Grok 4.5, and Composer 2.5." The second is "Other Models: The pool
  for third-party models, charged at the model's API price." Its priced models
  are Claude Fable 5.1, Claude Opus 5.5, Claude Sonnet 5.5, Gemini 3.1 Pro,
  Gemini 3.8 Flash, GPT-5.6 Luna, GPT-5.6 Sol, GPT-5.6 Terra and Muse Spark
  1.3.
  - Left out: Composer 2.5 (Cursor's own model, which has no card), and Gemini
    3.1 Pro. The catalogue has only "Gemini 3.1 Pro Preview", and a different
    name is not the same model.
- Coverage, Teams: not disclosed. The pool sentence names Pro, Pro Plus and
  Ultra only. The page does say that third-party model requests on Teams and
  Enterprise add "a Cursor Token Rate of $0.25 per million tokens".
- Allowance: "There are two separate usage pools, each resetting with your
  monthly billing cycle". The allowance in tokens is not published.
- Agent use: "Pro, Pro Plus, and Ultra include unlimited tab completions,
  extended agent usage limits on all models, access to Bugbot, and access to
  Cloud Agents." For Teams: "Cloud agents and automations with shared team
  context".
- Surfaces: `coding_tool:cursor`. The page is about Cursor itself. It does not
  say that the CLI (`cursor-agent`) draws on the plan, so that surface is left
  out.

## GitHub Copilot

Source: https://docs.github.com/en/copilot/get-started/plans
(`model-205-github-copilot-plans`), read over plain HTTP.

The "Available models" tables mark each plan's cell with an icon whose words
are its `aria-label` ("Included" or "Not included"). `html-default` drops
icons, so this source uses the new normaliser `html-icon-labels`. It is the
same recipe, but it renders a labelled icon as its label. `html-default` and
every other source's fingerprint are unchanged.

- Prices: "Copilot Pro | $10 USD per month (free for some users)", "Copilot
  Pro+ | $39 USD per month.", "Copilot Max | $100 USD per month", "Copilot
  Business | $19 USD per granted seat per month", "Copilot Enterprise | $39 USD
  per granted seat per month".
- Allowance: for Pro, Pro+ and Max, "Price per month | Base credits | Flex
  allotment | Total monthly AI credits": 1,000 / 500 / 1,500; 3,900 / 3,100 /
  7,000; 10,000 / 10,000 / 20,000. For Business and Enterprise, 1,900 and 3,900
  "GitHub AI Credits per user per month".
- Coverage: the "Included" rows of each plan's column.
  - Pro leaves out every Opus and Fable model, GPT-5.4 nano, GPT-5.5, GPT-5.6
    Sol, GPT-6 Astra and GPT-6 Sol.
  - Max leaves out Claude Sonnet 4.6.
  - Business and Enterprise leave out Claude Sonnet 4.6 and GPT-5.4 nano.
  - Names were matched to cards by display name, ignoring case and
    punctuation. "GPT-5 mini" matches `openai/gpt-5-mini` ("GPT-5 Mini"), and
    "GPT-5.3-Codex" matches `openai/gpt-5-3-codex` ("GPT-5.3 Codex").
  - Left out: MAI-Code-1.1-Flash (no card). "Claude Opus 4.8 (fast mode)
    (preview)" is a mode of Claude Opus 4.8, which is covered.
- Agent use and surfaces: "All plans include Copilot CLI and Copilot app." The
  surface is `coding_tool:copilot-cli`. Copilot in an IDE has no separately
  versioned harness to register (the VS Code extension's latest marketplace
  release is dated 2026-05-15), so it is not a surface yet. A spec with
  `coding_tool` and no harness still matches.

## Perplexity

Sources: https://www.perplexity.ai/pro (`model-205-perplexity-pro`) and the
help article
https://www.perplexity.ai/help-center/en/articles/10352901-what-is-perplexity-pro
(`model-205-perplexity-pro-help`). Both answer plain HTTP with a Cloudflare
challenge. Each retained copy is the rendered page's `document.body.innerText`,
read in a local browser (Playwright) after declining optional cookies. For the
pricing page, the FAQ answer "What models do I get access to?" was opened
first. No challenge had to be solved, and Firecrawl was not used.

- Price: "$17 /month when billed annually" (Pro) and "$167 /month when billed
  annually" (Max). That is a monthly equivalent of an annual price. The page
  does not state the billed amount, or whether a monthly plan exists, so price
  and billing period are `unknown`, not `not_disclosed`.
- Coverage, Pro: "Pro includes GPT-5.6 Terra, Claude Sonnet 5, Gemini 3.1 Pro
  Thinking, Grok 4.1, and Perplexity's in-house Sonar 2 model." That gives
  `openai/gpt-5-6-terra` and `anthropic/claude-sonnet-5`. The other three have
  no card.
  - The help article disagrees. It says "choose from Sonar (in-house model),
    GPT-5.2, Claude Sonnet 4.6, or Gemini 3.1 Pro", and was last modified on
    2026-09-03. The plan page is the current one, so it is the one recorded.
- Coverage, Max: not disclosed ("Frontier AI models").
- Allowance: "4,000 bonus credits" (Pro); "35,000 bonus credits", "10,000
  monthly credits" (Max).
- Agent use: "Expanded Computer access" (Pro) and "Maximum Computer usage"
  (Max). Perplexity Computer is its agent product.
- Surfaces: `chat_app`. The help article describes a subscription to
  Perplexity's own answer app. Its desktop and mobile apps are mentioned only
  for billing, so they are not claimed.

Perplexity is also a lab in the catalogue (`models/perplexity/sonar*.md`). Its
Sonar API is not a registered provider. If it becomes one, `perplexity` moves
from `subscription_vendors` to `providers`, because an ID cannot be in both.

`python scripts/model_205_collect.py --file`, and `modelspec verify` with a

sentence. Retained copies stay in the local CopyStore and are not committed.
