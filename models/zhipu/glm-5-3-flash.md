# GLM-5.3-Flash

First native multimodal model in the GLM-5 series. Distinct weights from GLM-5.3: a newly trained base, hybrid sparse + linear attention, MIT licence. The [provider blog](https://z.ai/blog/glm-5.3-flash) (2026-08-26) and [docs](https://docs.z.ai/guides/vlm/glm-5.3-flash) publish 320B total / 18B active, 1M-token context, 128K max output, and text + image + video input. Weights: [zai-org/GLM-5.3-Flash](https://huggingface.co/zai-org/GLM-5.3-Flash) (Hub safetensors total 321,323,031,390; `active_parameters` is the README 18B figure, not a safetensors count). Live AA/LM Arena standings from 2026-09-10 are attached. There is no dated eligibility score for Flash; the v4.2 gdpval 59 figure is GLM-5.3 (max), not this card.
