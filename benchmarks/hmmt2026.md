## What it measures

HMMT 2026 measures competition-style mathematical problem solving. The OpenCompass integration reads a `problem` field and asks a model to solve it, placing the final answer inside `\boxed{}`.

The benchmark is tied to the 2026 Harvard-MIT Mathematics Tournament. The inspected configuration does not document the problem count, contest sections, or difficulty distribution.

## How it is scored

OpenCompass uses a cascade evaluator. It first applies `MATHVerifyEvaluator`; when that rule evaluator does not decide the result, it uses a generic LLM judge with a grading prompt. The judge returns correct or incorrect decisions, so reported results depend on the fallback policy and judge model.

## Reading the numbers

A high score indicates success on this competition problem set under the configured answer checker. It does not establish general mathematical ability or resistance to prompt and judge variation. Report symbolic-verifier and LLM-judge outcomes separately when available.

The cascade tolerates equivalent expressions, but an LLM judge introduces another model’s interpretation. Preserve the rule-evaluator result and judge configuration for reproducibility.

Since the contest year is 2026, later revisions may change the problem set or answer files. Pin the dataset revision as well as the OpenCompass commit.
